# Elemental Frontier

A browser-based action RPG prototype with:

- party swapping across multiple characters
- elemental combat abilities and dodge movement
- quest progression and inventory tracking
- relic collection and shrine interactions
- enemy waves in a larger open map
- stylized anime-inspired combat visuals

## Run locally

```bash
cd elemental-adventure
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Controls

- W A S D / Arrow keys: move
- J: basic attack
- K: skill burst
- L: dash
- E: interact with relics and shrine
- 1-6: switch characters

## Gameplay loop

- Defeat raiders to progress the combat quest
- Collect relic fragments to satisfy the exploration objective
- Activate the shrine waypoint to complete the final quest
- Use inventory resources to support progression
